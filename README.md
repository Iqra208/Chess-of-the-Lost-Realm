# 🌌 Welcome to ChessWorld

**ChessWorld** is not just an ordinary chess game.

It is a journey into an **imaginary fantasy universe** where the chessboard becomes a gateway to another world.

When players start the game, they enter a mysterious realm filled with magical environments, cinematic moments, atmospheric sounds, and an immersive chess experience.

> ♟️ **Move the piece. Enter the realm. Change the story.**

# 🚀 Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/ChessWorld.git
```

## 2️⃣ Enter the Project

```bash
cd ChessWorld
```

## 3️⃣ Run Locally

For a simple static version, open:



Then open:

```text

```

# 🌐 Deploy on Vercel

ChessWorld is designed to work with **Vercel**.

### Deployment Steps

1. Push the project to GitHub.
2. Open Vercel.
3. Select **Add New Project**.
4. Import the ChessWorld repository.
5. Select the project.
6. Click **Deploy**.
7. Your game will receive a live Vercel URL.

### ⚡ Vercel Configuration

The project includes:

```text
vercel.json
```

to support the web deployment.
